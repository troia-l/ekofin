# 🌱 EcoFin | Yapay Zeka Destekli Yeşil Enerji Finansmanı

EcoFin, işletmelerin ve bireylerin karbon nötr hedeflerine ulaşmasını hızlandırmak için geliştirilmiş, **yapay zeka (AI) destekli sürdürülebilirlik denetimi ve yeşil finansman platformudur.** Şeffaf, veri odaklı ve greenwashing'den uzak bir yatırım ekosistemi sunar.

![EcoFin Dashboard Preview](https://images.unsplash.com/photo-1497366216548-37526070297c?q=80&w=2069&auto=format&fit=crop)

## 🚀 Projenin Amacı

EcoFin, klasik bankacılık süreçlerini ve yüzeysel ESG (Çevresel, Sosyal ve Kurumsal Yönetişim) beyanlarını geride bırakarak; uydu verileri, IoT sensörleri ve çapraz veri kaynakları ile projelerin **gerçek çevresel etkisini** saptar. Şirketlere adil finansman imkanı sunarken, bireysel yatırımcıları da yeşil dönüşüme kitle fonlaması yoluyla dahil eder.

## ✨ Temel Özellikler

- **🏢 Kurumsal Yeşil Paneli:** Bankalar ve holdingler için tasarlanmış, B2B entegrasyonuna uygun kurumsal dashboard.
- **💰 A.I. Destekli Kredi Pazar Yeri:** İşletmeler için ESG skorlarına göre optimize edilmiş düşük faizli yeşil kredi fırsatları.
- **🤝 Kitle Fonlaması (Crowdfunding):** Bireylerin binlerce liralık bütçelerle güneş ve rüzgar enerjisi projelerine ortak olmasına olanak sağlayan modern borsa arayüzü.
- **🔍 A.I. ESG Raporu (Greenwashing Kalkanı):** Anlık şirket araması ile NLP ve API entegrasyonlu veri analizleri. Karbon ayak izi gerçekliğini puanlayan dinamik "Güven Endeksi".

## 🛠 Kullanılan Teknolojiler

- **Frontend Core:** React.js, Vite
- **Routing:** React Router DOM (HashRouter)
- **Styling:** Vanilla CSS, CSS Variables, Flexbox/Grid
- **İkonlar:** Lucide React
- **Dağıtım (Deployment):** GitHub Pages & GitHub Actions (CI/CD)
- **Assets:** Unsplash API (Yüksek Karbon Nötr konseptli resimler)

## 📦 Kurulum ve Çalıştırma

Projeyi kendi bilgisayarınızda çalıştırmak için:

1. Depoyu bilgisayarınıza klonlayın:
   ```bash
   git clone https://github.com/Bekir-Caglar/EcoFin.git
   ```
2. Proje dizinine girin:
   ```bash
   cd EcoFin
   ```
3. Gerekli paketleri kurun:
   ```bash
   npm install
   ```
4. Geliştirme sunucusunu başlatın:
   ```bash
   npm run dev
   ```
